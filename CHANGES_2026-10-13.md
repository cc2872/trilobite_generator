# Changes, 12-13 October 2026

## The studio is the front page (12 Oct)

`/` now serves the **studio** (`web/studio.html`), the combined head + body editor, and the parametric
generator moved to **`/generator`** (`web/index.html`). The studio draws the whole animal from the
builder's own geometry (`/api/head_diagram` + `/api/body_diagram`), edits the head shape, the body rows,
the P-eye (a side diagram with draggable stalk / lean / height) and the prongs (head + tail tine steppers
and sliders), and its **BUILD** draws the blueprint over the drawing with a BLUEPRINT / VIEW 3D toggle and
an "editor" return. VIEW 3D embeds `/generator?only3d=1` (the generator's three.js viewer, panel hidden),
carrying the live animal through the sessionStorage draft. Build / sheet / 3D all use the same P + head +
body spec, so what you shape is what builds. Family-tree button added to the studio; the two separate
`/head` and `/body` editors stay for now.

Also: every em-dash / middle-dot in the web UI replaced with plain hyphens; a stacked single-column mobile
layout (drawing on top, controls below) under 760 px for the studio and the editors (the generator and the
tree page were already responsive).

## Security pass (13 Oct, review Part A)

Closed the live-server holes: validated the cache key on `/files/<key>` and `/api/stl/<key>` (was a path
traversal that could read `web/agent_token.txt`); capped the power exponent in the AST expression evaluator
(`9**9**9` could hang inside the build lock); `schema.coerce` now sends bool / NaN / inf / non-numeric to the
param default instead of into a hash, JSONL, the geometry or an HTML 500; `MAX_CONTENT_LENGTH` = 2 MB; the
saved-name regex uses `\Z` not `$` and a 500-item cap; the agent token uses `hmac.compare_digest` and
`/api/agent/log` is 404 unless a token is configured; `.dockerignore` keeps secrets and runtime data out of
the image; `?p=` accepts only finite numeric known params (no string to `innerHTML`); the cutter pool has a
240 s timeout so an OOM-killed worker can't hold the build lock forever.

## Rows-model fidelity locked in (13 Oct, review Part B)

A per-preset diagnostic confirmed the rows model reproduces the generator's own thorax and tail to machine
epsilon for all ten orders; the only deviations are agnostida's macro width (the macro is a lossy projection,
~5.6 %) and the dev preset `reference`'s tail. `test_fidelity_and_macro_hold_for_every_preset` now loops the
fidelity and macro checks over every preset (was default-only). `validate_list` refuses a thoracic row after
a pygidial one (400) instead of silently folding it into the tail.

## `/generator` retired as a page, kept as a backend (13 Oct, review Part K)

The generator is no longer presented as a co-equal editor: the studio's nav button is relabelled
"measure / advanced" (the full parameter set, the enrollment instrument / ruler, landmarks and share live
there). The `/generator` **route is kept** because the studio's VIEW 3D embeds it (`?only3d=1`) and MEASURE
is the only UI for the instrument; nothing is deleted. Decision: retire as a page, not remove the code
(rescuing the 3D viewer and MEASURE into the studio is a later block).
