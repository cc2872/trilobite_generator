# Earth model

`Earth.stl` is the globe Claire uploaded on 3 Oct 2026 (61,442 vertices, radius about 39.3 with the land raised). The tree page's Earth layout draws its land from it: `make_mask.py` samples the relief and prints the land mask `web/tree.html` carries.
